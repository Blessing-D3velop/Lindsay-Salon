
# Sky Angels Kiddies Hair Salon Website

A modern, responsive website built for Sky Angels Kiddies Hair Salon.  
The website showcases professional kids’ hair services in a fun, safe, and family-friendly environment while making it easy for clients to view services and book appointments.

Built With

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Responsive Design (Flexbox & Media Queries)




Features

- Modern landing page for a kids hair salon
- Services section (braids, styling, treatments, etc.)
- Gallery showcasing client hairstyles
- Contact section with WhatsApp and email integration
- Mobile-friendly navigation
- Smooth scrolling and interactive UI
- Clean, child-friendly UI design



Project Purpose

This website was built for Sky Angels Kiddies Hair Salon to provide an online presence where parents can view services, explore hairstyles, and easily contact the salon for bookings.



Responsiveness

The website is fully responsive and optimized for:
- Mobile devices
- Tablets
- Desktop screens
